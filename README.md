# Khat – Email Notification Platform

Khat is a full-stack email notification platform that allows authenticated users to send email notifications to one or multiple recipients and track their delivery history.

## Tech Stack

- **Frontend:** React
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **Authentication:** JWT, bcrypt
- **Email Service:** Nodemailer, Gmail SMTP

## Features

-  User registration and login
-  JWT-based authentication and protected routes
-  Secure password hashing using bcrypt
-  Send email notifications to one or multiple recipients
-  Recipient validation and duplicate recipient removal
-  Dashboard with delivery statistics
-  Notification delivery history
-  Track `SENT` and `FAILED` delivery status
-  PostgreSQL database for persistent data storage
-  Nodemailer integration with Gmail SMTP
-  Input validation and error handling
-  CORS configuration
-  Backend health-check endpoint
-  Input length limits for safer API requests

##  Project Overview

Khat provides a simple dashboard where authenticated users can compose and send email notifications.

Users can:

1. Register an account
2. Log in securely
3. Send notifications to multiple recipients
4. View delivery statistics
5. Track notification history
6. Check whether emails were successfully sent or failed
